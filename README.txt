LOTTO AI 모바일 (안드로이드 설치형 웹 앱)
=========================================
PC 프로그램(lotto_strategy_gui_combined_random_kick_off_21.0.py)과 별개로 휴대폰 안에서 혼자 동작합니다.
번호 선정 로직은 PC 21.1과 같고(같은 데이터에서 같은 번호), 화면·저장만 휴대폰용으로 만들었습니다.

[폴더 구성]  이 mobile 폴더 안의 파일 전체가 앱입니다.
  index.html / app.js     화면, 저장, 채점
  worker.js               파이썬 엔진을 돌리는 작업 스레드
  engine_mobile.py        번호 선정 엔진 (PC 21.1에서 엑셀·화면 부분만 뺀 것)
  seed_draws.json         처음 들어 있는 당첨번호 (1249회까지, 새로 설치하는 경우에만 쓰임)
  sw.js, manifest.webmanifest, icon-*.png   오프라인 실행과 앱 설치용

[1. 한 번만 웹에 올리기]  (설치형 앱은 https 주소에서만 설치할 수 있습니다)
  예) GitHub Pages
    1) GitHub 저장소를 만들고 mobile 폴더 안의 파일들을 저장소 맨 위에 올립니다. (폴더째가 아니라 안의 파일들)
    2) 저장소 Settings > Pages 에서 main 브랜치를 선택합니다.
    3) 몇 분 뒤 https://아이디.github.io/저장소이름/ 주소가 생깁니다.
  (Netlify 등 정적 파일을 올릴 수 있는 곳이면 어디든 됩니다.)

[2. 휴대폰에서 설치]
    1) 휴대폰 크롬으로 위 주소를 엽니다.
    2) '추천 받기'를 한 번 누릅니다. 이때 파이썬 엔진과 라이브러리(약 41MB)를 내려받으므로 와이파이를 권장합니다.
       처음 추천은 1분 안팎, 이후에는 기기에 저장되어 더 빨라집니다. (추천 1회 약 30초~1분, 폰 성능에 따라 다름)
    3) 크롬 메뉴(⋮) > '앱 설치' 또는 '홈 화면에 추가'를 누르면 앱 아이콘이 생깁니다.
    4) 이후에는 인터넷 없이도 실행됩니다.

[3. 사용]
    추천 탭  : '추천 받기'로 하이브리드 5세트와 무작위 5세트를 만들고 기록합니다.
    데이터 탭: 새 회차 당첨번호(번호 6개 + 보너스)를 입력하면 해당 회차 추천이 자동 채점됩니다.
    성적 탭  : 누적 승패와 회차별 상세, 과거 되감기(그 직전까지의 데이터만으로 다시 추천해 채점).

[4. 백업]
    데이터는 휴대폰 브라우저 안에만 저장됩니다. 브라우저 데이터를 지우면 사라지므로
    데이터 탭의 '내보내기'로 가끔 백업 파일을 저장해 두세요. ('가져오기'로 복원)

[5. 앱을 고쳤을 때]
    파일을 다시 올린 뒤 sw.js 의 SHELL 이름(lotto-shell-v1)을 v2, v3 ... 로 올리면 휴대폰에 새 버전이 적용됩니다.

[PC에서 시험 실행]
    mobile 폴더에서  python -m http.server 8765  을 실행하고 크롬으로 http://localhost:8765 를 엽니다.
